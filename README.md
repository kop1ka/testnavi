# Flask приложение для управления мультимедийным контентом

Приложение для парсинга FTP-каталога, редактирования мультимедийного контента и экспорта данных в JSON.

## Возможности

1. **Редактирование мультимедийного контента** - страница администрирования `/admin` позволяет:
   - Просматривать структуру каталога в виде дерева
   - Редактировать элементы (название, URL, дату модификации, иконку)
   - Отмечать элементы как постоянные

2. **Парсер FTP-каталога** - кнопка запуска парсера читает данные с https://vm-ftp.anosov.ru/vm/:
   - Рекурсивно обходит все папки
   - Извлекает информацию о файлах и папках
   - Сохраняет дату модификации и URL
   - Автоматически определяет тип элемента (папка/файл)

3. **Постоянные элементы** - возможность сохранить элементы от изменений при парсинге:
   - Элементы помечаются как "permanent"
   - При запуске парсера постоянные элементы не обновляются
   - Можно добавлять/удалять элементы из списка постоянных через админ-панель

4. **Экспорт/Импорт JSON**:
   - Выгрузка текущего каталога в JSON файл
   - Загрузка каталога из JSON файла
   - API endpoint `/api/catalog/export` для программного доступа

## Установка

### Требования
- Python 3.8+
- Flask 3.x
- requests
- beautifulsoup4

### Установка зависимостей

```bash
pip install flask requests beautifulsoup4
```

## Запуск

```bash
python app.py
```

Приложение будет доступно по адресу: http://localhost:5000

## API Endpoints

### Каталог
- `GET /api/catalog` - получить текущий каталог
- `GET /api/catalog/export` - экспорт каталога в JSON
- `POST /api/catalog/import` - импорт каталога из JSON
- `PUT /api/items` - обновить элемент каталога

### Парсер
- `GET /api/parser/status` - получить статус парсера
- `POST /api/parser/run` - запустить парсер

### Постоянные элементы
- `GET /api/permanent` - получить список постоянных элементов
- `POST /api/permanent` - добавить элемент в постоянные
- `DELETE /api/permanent` - удалить элемент из постоянных

## Использование админ-панели

1. Откройте http://localhost:5000/admin
2. Для запуска парсера нажмите кнопку "🚀 Запустить парсер"
3. Для редактирования элемента:
   - Выберите элемент в дереве каталога
   - Измените поля в редакторе
   - Нажмите "💾 Сохранить"
4. Для добавления элемента в постоянные:
   - Выберите элемент
   - Нажмите "🔒 Добавить в постоянные"
   - Или установите чекбокс "Постоянный элемент"
5. Для экспорта каталога нажмите "📥 Экспорт JSON"

## Формат данных

Каталог хранится в формате JSON со следующей структурой:

```json
{
  "name": "Название элемента",
  "icon": "folder.png",
  "children": [],
  "url": "https://...",
  "modified": "2026-03-07 14:06",
  "permanent": true
}
```

Поля:
- `name` - название элемента
- `icon` - имя файла иконки
- `children` - массив дочерних элементов (для папок)
- `url` - URL файла (для файлов)
- `modified` - дата последней модификации
- `permanent` - флаг постоянного элемента (опционально)
