# Папка проектов

В эту папку загружаются проекты, которые будут отображаться в каталоге как постоянные элементы.

## Структура проекта

Каждый проект должен быть размещён в отдельной подпапке и содержать файл `index.html`.

Пример структуры:
```
projects/
├── project1/
│   └── index.html
├── project2/
│   ├── index.html
│   ├── style.css
│   └── script.js
└── flask_app/
    ├── index.html
    └── app.py
```

## Как это работает

1. Название папки проекта становится элементом в каталоге
2. Файл `index.html` внутри папки становится ссылкой на этот элемент
3. Проекты являются постоянными элементами и не удаляются при парсинге FTP-каталога

## Доступ к файлам проекта

Файлы проектов доступны по URL: `/projects/<название_папки>/<файл>`

Например:
- `/projects/test_project/index.html`
- `/projects/my_flask_app/static/style.css`
