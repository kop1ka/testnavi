📋 О проекте

Это шаблон проекта для демонстрации архитектуры с использованием Flask Blueprint.

Проект автоматически регистрируется в главной системе при запуске приложения.

Возможности:

  • Автоматическая регистрация через create_blueprint()
  • Изолированные шаблоны и статические файлы
  • Поддержка API endpoints
  • Легко масштабировать - просто добавьте новую папку в projects/
